Entrants write one sentence, at most 280 characters, that brings back a childhood memory. The house judge compares lines in pairs and the most nostalgic one takes the whole $2.

## Entry

The entry is a single line in `entry.txt`:

> Grandma's kitchen at dusk: rice steaming, the radio humming an old song, and her hand on my shoulder saying food tastes better when we wait together.

## How it works

`main.py` (Python standard library only) copies the committed `entry.txt`
into the harness output directory (`$MAKEFUN_OUTPUT_DIR`, default `out/`).

Run it locally:

```sh
python3 main.py
```
